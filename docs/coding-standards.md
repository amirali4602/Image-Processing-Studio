# Coding Standards

## Python

- Follow PEP8.
- Use type hints where appropriate.
- One class per file.

## GUI

- GUI widgets should not call OpenCV directly.
- GUI communicates through controllers.

## Filters

- Each filter has its own module.
- Filters are stateless.

## Naming

Classes:
PascalCase

Methods:
snake_case

Constants:
UPPER_CASE
